# 远程授权系统实现计划

## 概述

为 Certd Electron 客户端实现远程授权系统，支持按订阅付费销售软件。

## 目录结构

```
certd/
├── certd-electron/          # 客户端（已有）
│   └── electron/
│       └── services/
│           └── license-service.js  # 新增：授权验证服务
├── certd-license-server/    # 新增：授权服务器
│   ├── src/
│   │   ├── routes/
│   │   ├── services/
│   │   └── models/
│   └── package.json
```

## 技术栈

### 授权服务器
- 框架：Express.js / Koa
- 数据库：PostgreSQL / MySQL
- ORM：Sequelize
- 缓存：Redis
- 支付：微信支付 SDK、支付宝 SDK

### 客户端
- 授权验证：license-service.js
- 设备指纹：基于硬件信息生成
- 本地缓存：electron-store
